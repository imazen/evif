FFmpeg decoded each extracted APNG; every frame sample hash matched, including
transparent RGB and low bits. Python independently checked CICP, durations and
PNG CRCs. FFmpeg's APNG demuxer required seekable input; the oracle retains exact
payload extractions beside the fixtures. This is read-back only, not encoding.

The Rust suite also checks raw floating-point bits, strided rows, external storage,
storage-independent identities, append/truncation behavior, duplicate JSON keys,
resource limits, and offsets beyond 4 GiB using a virtual stream. The CLI test
checks actual PNG decoding, existing-output preservation and exact score JSON
pass-through. Native video metric adapters and display rendering are not tested.

[Core CI](https://github.com/imazen/evif/actions/runs/40173177720) passed all required
jobs, including i686, Windows ARM64 and macOS ARM64. Later CLI/oracle changes are
covered by the PR's subsequent checks.
