The existing sequence-carrier test writes two symmetric RGBA16 assets per
file, each with three 13x9 frames and exact rational timing. The independent
Python oracle parses the wire and recomputes media roots. FFmpeg decodes each
APNG; the C xxHash shared library verifies XXH3-128 over the canonical frame
descriptor and decoded samples. SHA-256, CICP, PNG CRCs and durations also match.
Both assets have the same identity in each file:

- PQ: `4693dec9ae72b5d85cb22825aaca2a850b9c027f0d4f7b62940e16686d6cfa9b`.
- HLG: `b4d26599e41897942fe144a9d9fe29c6de4f7a4c4caa8b34c651239b0119e594`.

Rust checks compare zenhash with independent `xxhash-rust` results across
short/long inputs and u8/u16/f16/f32 samples. They verify strided rows, padding
exclusion, optional-check independence, high/low digest-half binding, canonical
32-digit serialization and refusal of the old 64-bit schema.
