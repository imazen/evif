The independent Python oracle recomputed the media roots and used FFmpeg plus
the system xxHash C library to verify both frame digests against decoded samples.
It also checked CICP, timing and PNG CRCs. Its roots matched the Rust writer:

- PQ: `125139e05ceebbc5cbfbcdbb2e7641293c118397976b76b568d4a2b3313c1ffe`.

The Rust tests compare XXH3 with the independent `xxhash-rust` implementation
over short/long inputs and u8/u16/f16/f32 sample bytes. They check that stride
padding is excluded, sample changes affect both digests, XXH3-only and dual-hash
paths agree, and optional SHA-256 presence/value does not change media identity.
Canonical hash spelling is enforced, and SHA-only draft sample fields are refused.
