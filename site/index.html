EVIFThe evil image format.

Find the images your quality metric gets wrong.

Open the coffin  ↓

A container and a probe for stress-testing image quality metrics such as SSIMULACRA2, butteraugli and zensim. An .evif file holds a distorted image made by pushing a real encoder's knobs where no sane encoder goes, the recipe, the lossless pixels our decoder produced, and the score every metric gave it. Anyone can re-run the metrics and check the recorded scores.

Why

Fixed datasets such as KADID-10k and TID2013 show whether a metric ranks everyday distortions the way people do. They cannot show what an optimizer finds when it pushes against the metric, and that is how metrics are used: inside encoder tuning, rate-distortion search and codec pickers. EVIF runs a maximum-differentiation search (after Wang & Simoncelli, 2008) over codec parameters rather than pixels, so every finding is a bitstream a real decoder reads and a file size that is real.

Possess

Take a real encoder's full parameter vector: per-band quantization, zero-bias, chroma subsampling, adaptive quantization, deringing, trellis.

Judge

Score every sample with several metrics, each pinned to a revision, against the family's honest rate-distortion curve at the same bits per pixel.

Record

Store one lossless reference decode, the recipe and every score. Keep candidate bytes or omit them with their size and checksum recorded. evif verify checks the reference pixels; evif extract exports retained candidate bytes.

What is in the coffin

chunkholds
HEADdimensions, channel layout, sample type
BITSoptional candidate bytes, including external codecs or EVIF-specific compression
BINFrecorded candidate codec, encoded size and checksum when bytes are omitted
PNGF / IMIJone lossless reference decode: the exact pixels the metrics scored
DIGSXXH3-64 digests of the distorted and reference rasters
clamthe size a synthetic distortion pretends to cost
srce knob scorsource id, the recipe, and every score with metric, variant, version and implementation
SEALXXH3-64 of the whole file before it

Upper-case first letter: critical. Lower case: ancillary. Byte layout in SPEC.md.

Get it

git clone https://github.com/imazen/evif
cd evif && cargo build --release
target/release/evif probe --family zenjpeg-expert --target ssim2 --out out corpus/*.png
